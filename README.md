# AgriSense AI

AgriSense AI is a FastAPI + React decision-support application that recommends a crop from measured field conditions. Predictions, confidence scores, alternatives, metrics, and feature importance are generated by the trained scikit-learn model—not hardcoded UI data.

## Dataset

- **Name:** Crop Recommendation Dataset
- **Source:** Kaggle, *Crop Recommendation Dataset* (widely mirrored from the Crop Recommendation Dataset)
- **URL:** https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset
- **Size:** 2,200 records, 22 balanced crop classes
- **Features:** N, P, K, temperature, humidity, ph, rainfall
- **Target:** label (crop)
- **License:** Refer to the source dataset terms on Kaggle.
- **Preprocessing:** validates expected columns and numeric values, drops missing and duplicate records if present; no synthetic data is created.

## Start on Windows

Backend:

```powershell
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python train_model.py
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Frontend (new terminal):

```powershell
cd frontend
copy .env.example .env
npm install
npm run dev -- --host 0.0.0.0
```

Open `http://localhost:5173`. For LAN access, set `VITE_API_URL=http://<HOST-PC-IP>:8000` in `frontend/.env`, then restart Vite. Add that frontend origin to the FastAPI CORS list in `backend/app/main.py` when needed.

## API

- `GET /api/health`
- `GET /api/model-info`
- `GET /api/model-comparison`
- `POST /api/predict`

The system is intended for educational decision support and does not replace local agricultural expertise. Future extensions include weather APIs, soil sensors, disease detection, yield modelling, satellite imagery, and irrigation recommendations.
